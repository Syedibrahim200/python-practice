SABIQ WEB STUDIO — ANIMATED PORTFOLIO
=====================================

Open index.html to view the main portfolio.

Four demo sites, each with a different visual identity:
1. Coastal Bites — warm coastal restaurant
2. DriveCraft Auto — dark performance automobile
3. Urban Glow — editorial beauty/salon
4. Nestora Realty — luxury real-estate / green glass theme

Every demo links back to the main portfolio with the "← Portfolio" button.
The main portfolio links to every demo.

All projects are fictional portfolio concepts. Replace demo contact/booking
actions with the client's real WhatsApp, email, forms, maps or booking system
before selling/deploying.

No external libraries are required; everything is contained in each HTML file.
